# SafeClaw 产品需求文档 (PRD)

> 基于 OpenClaw 设计思想的安全导向本地 AI 助手
> Streamlit + Python 3.10+ 实现

---

## 1. 产品概述

### 1.1 产品名称
SafeClaw（安全之爪）

### 1.2 产品定位
一个**安全优先**、**文件优先**的本地 AI 助手，借鉴 OpenClaw 的设计思想，使用 **Streamlit + Python** 技术栈实现。目标是成为开发者日常工作的可信助手，所有数据本地可控，操作透明可审计。

### 1.3 目标用户
- Python 开发者
- 注重隐私的技术用户
- 需要本地 AI 辅助的独立开发者

### 1.4 核心价值主张
| 特性 | 价值 |
|------|------|
| **本地优先** | 数据不出境，隐私完全可控 |
| **文件优先** | 所有配置和记忆都是可编辑的 Markdown/JSON |
| **安全导向** | 敏感操作二次确认，代码沙箱执行 |
| **简单易用** | Streamlit 单页应用，无需守护进程 |
| **可扩展** | 技能系统支持自定义功能 |

## 2. 功能需求

### 2.1 核心功能

#### FR-001 多会话聊天
- 支持创建多个独立会话（类似聊天应用的多个对话）
- 每个会话有独立的上下文和历史
- 会话可命名、搜索、归档

#### FR-002 文件优先配置
- 配置存储为 JSON 文件，可手动编辑
- Agent 提示词存储为 AGENTS.md
- 人格定义存储为 SOUL.md
- 用户偏好存储为 USER.md

#### FR-003 记忆系统
- **活跃记忆**：当前会话的近期对话，高频访问信息
- **沉睡记忆**：历史对话和经验，需要条件唤醒
- **深层记忆**：核心偏好和价值观，相对稳定
- **记忆唤醒**：关键词刺激、情境关联、时间触发、情绪共鸣
- **记忆遗忘**：逐步淘汰错误、负面、干扰性记忆
- **记忆精华化**：实事求是、自洽统一、趋利避害、成长导向
- **可选向量检索**：启用后使用 ChromaDB 语义搜索

#### FR-004 LLM 集成支持
- SafeClaw Agent **不直接与 LLM 通信**
- **通过 DeepAgents 框架**调用 LLM 提供商
- DeepAgents 框架负责 LLM 调用、工具执行、状态管理
- 支持 OpenAI GPT-4/GPT-3.5、Anthropic Claude、本地模型（Ollama）
- 统一接口，可热切换

#### FR-005 智能技能系统（基于 LangGraph DeepAgents）
- **SafeClaw 核心能力**：文件操作、记忆管理、对话交互、基础搜索、DeepAgents接口
- **业务技能（Skills）**：代码分析、数据处理、图表生成等业务层面功能
- **技能定义**：SKILL.md + main.py，继承 BaseSkill 接口
- **内置技能**：文件操作、代码分析、命令执行、网络请求
- **自定义技能**：用户可添加自己的技能，支持热加载
- **技能发现**：自动扫描 skills/ 目录，动态注册
- **LLM 理解机制**：
  - 技能自动转换为 LLM 可理解的 ToolDefinition
  - 基于 JSON Schema 的标准化参数描述
  - 智能工具选择器，根据用户输入自动选择合适技能
  - 动态提示词注入，工具描述实时更新
- **DeepAgents 集成**：
  - LangGraph 状态图管理技能调用流程
  - 多技能组合执行支持
  - 技能执行结果自动整合到对话上下文

#### FR-006 安全控制
- **三级安全策略**：
  - **黑名单操作**：完全禁止（格式化系统、修改 BIOS 等）
  - **白名单操作**：自动允许（文件读取、记忆查询、聊天响应等）
  - **确认操作**：用户确认（文件删除、系统命令、网络请求等）
- **敏感操作确认**：删除、系统命令、网络请求需确认
- **API 密钥加密存储**：使用系统 keyring 或文件加密
- **代码沙箱**：技能代码受限执行
- **操作日志**：所有敏感操作记录审计日志

### 2.2 界面功能

#### FR-007 Streamlit UI
- **聊天界面**：类 ChatGPT 的对话界面
- **侧边栏**：会话列表、模型选择、设置入口
- **会话管理页**：新建/删除/重命名会话
- **记忆浏览页**：查看和搜索历史记忆
- **设置页**：LLM 配置、安全设置、关于

#### FR-008 流式响应
- LLM 响应实时流式显示（打字机效果）
- 支持中断生成

#### FR-009 消息操作
- 复制消息内容
- 重新生成回复
- 删除单条消息

### 2.3 高级功能（二期）

#### FR-010 工具调用
- LLM 可调用定义的工具
- 工具结果实时显示
- 支持自定义工具

#### FR-011 RAG 支持
- 上传文档到知识库
- 对话时基于文档回答
- 支持 PDF、Markdown、代码文件

#### FR-012 代码解释器
- 安全执行 Python 代码
- 结果显示图表和输出
- 状态持久化

## 3. 非功能需求

### 3.1 性能需求
- **启动时间**：Streamlit 应用冷启动 < 3 秒
- **响应延迟**：首 token 延迟 < 2 秒（网络正常时）
- **并发**：单用户，无需考虑多并发
- **内存**：正常工作内存占用 < 500MB

### 3.2 安全需求
- **数据本地**：默认所有数据本地存储
- **密钥加密**：API 密钥必须加密存储
- **操作审计**：敏感操作记录日志
- **沙箱执行**：技能代码受限执行
- **无外部调用**：除非用户明确授权

### 3.3 可靠性需求
- **文件持久化**：会话和记忆实时写入文件
- **优雅降级**：LLM 不可用时给出清晰提示
- **配置校验**：启动时验证配置有效性

### 3.4 易用性需求
- **零配置启动**：首次使用引导配置
- **热重载**：修改配置文件无需重启
- **错误提示**：清晰的错误信息和解决建议

## 5. 用户旅程

### 5.1 首次使用
1. 用户安装：`pip install safe-claw`
2. 启动应用：`safe-claw` 或 `streamlit run app.py`
3. 首次引导：
   - 选择 LLM 提供商
   - 输入 API 密钥（加密存储）
   - 创建工作区
4. 开始对话：自动创建 "default" 会话

### 5.2 日常对话（DeepAgents 流程）
1. 在聊天框输入问题
2. DeepAgents 状态图自动处理：
   - **输入分析**：识别是否需要技能调用
   - **工具选择**：智能选择合适的技能组合
   - **记忆检索**：自动检索相关历史记忆
   - **技能执行**：并行或串行执行选定技能
   - **结果整合**：将技能执行结果整合到上下文
   - **响应生成**：LLM 基于完整上下文生成响应
   - **记忆更新**：提取重要信息更新长期记忆
3. 用户可：切换会话、查看记忆、调整设置

### 5.3 技能使用（LLM 驱动）
1. 用户请求需要技能支持的操作
2. DeepAgents 自动：
   - 将技能转换为 LLM 可理解的 ToolDefinition
   - 基于用户输入和上下文智能选择技能
   - 动态生成包含工具描述的提示词
   - 执行技能并处理结果
3. 如有敏感操作，弹出确认对话框
4. 技能执行结果自动整合到回复中

## 8. 附录

### A. 术语表
- **Session（会话）**：一个独立的对话上下文
- **Skill（技能）**：可扩展的功能模块，继承 BaseSkill 接口
- **Tool（工具）**：LLM 可理解的技能表示，基于 ToolDefinition
- **DeepAgents**：基于 LangGraph 的智能代理架构
- **LangGraph**：状态图管理框架，控制技能调用流程
- **Memory（记忆）**：长期保存的重要信息
- **Gateway**：LLM 调用抽象层
- **Context（上下文）**：组装后的提示词和背景信息
- **ToolDefinition**：技能的标准化描述格式
- **SkillToolAdapter**：技能到工具的转换器

### C. DeepAgents 架构图

```
用户输入
    │
    ▼
┌───────────────────────────────┐
│      DeepAgents 状态图        │
│  (基于 LangGraph)             │
└──────────────┬────────────────┘
               │
               ├─ 分析输入 (需要技能?)
               ├─ 选择工具 (智能选择器)
               ├─ 检索记忆 (相关历史)
               ├─ 执行技能 (并行/串行)
               ├─ 整合结果 (上下文)
               ├─ 生成响应 (LLM)
               └─ 更新记忆 (长期存储)
```

### D. 技能到工具转换流程

```
Skill (Python 类)
    │
    ▼
SkillToolAdapter
    │
    ├─ 提取技能描述
    ├─ 生成 JSON Schema
    └─ 创建工具函数
    │
    ▼
ToolDefinition (LLM 可理解)
    │
    ▼
LangChain Tool
    │
    ▼
LLM 调用
```
