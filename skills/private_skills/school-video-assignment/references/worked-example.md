# 真实案例：小学「红色故事我来讲」宣讲视频

留着这份是为了让后来者知道**每一步大概能改善多少**，以及**哪些问题是转写才能发现的**。

## 背景

- 作业要求：MP4 / ≤5 分钟 / ≤200 MB / 戴红领巾 / 出现上海红色地标
- 讲的人物：钱学森；地标：上海交通大学钱学森图书馆
- 恶劣天气去不了现场，在家录了 202 秒（960×544，30 fps）
- 配图：家长手上的图书馆照片 + Wikimedia Commons / 官网公开图，共 14 张底板

## 转写发现了什么

用 FunASR 拿到字级时间戳后，问题一目了然，而这些**看片子是发现不了的**：

### 内容硬伤（最有价值的发现）

原始音频和降噪音频**两遍转写给出同样的错误**，指向真的念错了：

| 时间 | 听到 | 应为 | 性质 |
|---|---|---|---|
| 10.7s | 东**方**二号甲 | 东**风**二号甲 | 东风是导弹，东方红是卫星，念混是硬伤 |
| 74.2s | 五个**十**的兵**例** | 五个**师**的兵**力** | 成语式引用念错 |
| 80.6s | **钱修森**（连着两次） | 钱**学**森 | 主角名字念错 |

反过来，结尾一句原始识别为「汪荣之城」、降噪后识别为「**光荣之城**」——两遍不一致，说明是噪声导致的误识，孩子念对了，不用补录。

**这就是双跑对比的价值**：把「要补录的」和「虚惊一场的」分开。

### 没剪掉的重录

| 源时间 | 内容 | 处理 |
|---|---|---|
| 144.9–152.4s | 「这就是一场……（卡 2.6 秒）……那一刻，我明白了」整段重录 | 删 7.5s |
| 169.9–176.1s | 「月亮出差……（卡 3.4 秒）……七」 | 删 6.2s，接成「嫦娥号去｜月亮出差」 |
| 160.4–164.9s | 3.5 秒空白 + 多出来的一个「今」字 | 删 4.5s |
| 179.5–180.2s | 「新的**长长**征」 | 删 0.7s |

保留了结尾的「就是新的长征，就是新的长征」——那是排比强调，不是失误。**这条只能人判断**。

另有 14 处 1–3 秒的过长停顿被压到 0.5–1.4 秒。

合计剪掉 **33.3 秒**：202.0s → **168.8s（2:49）**。全片原本有 36 段停顿共 64.2 秒，占三分之一。

## 各项改善的量化

| 项目 | 改前 | 改后 |
|---|---|---|
| 时长 | 202.0s | 168.8s |
| 音频峰值 | **+2.16 dB**（削波） | −1.43 dB |
| 平均音量 | −16.0 dB | −16.7 dB |
| 停顿处底噪 | −34.7 dB | **−61.4 dB** |
| 源信噪比 | 人声 −39.6 / 底噪 −55.0 = 15 dB | — |
| 降噪后逐字稿 | — | 与原始一致，**无丢字** |
| 分镜 | 时间靠估 | 22 段，全部对齐讲词 |

## 画面上修掉的两处

1. **左下角悬浮矩形**：人物离画面底边留了 14 px，源视频切平的腿部平边就成了一个可见的方块。改成贴底解决。
2. **挥手时胳膊半透明**：运动模糊导致 alpha 只有 0.3–0.6，能看见背后的建筑。加 alpha 对比度曲线（0.6 以上推成不透明）后明显改善，但源素材的运动模糊本身救不回来，手部仍偏软。

## 耗时

| 步骤 | 耗时 |
|---|---|
| FunASR 转写 202s 素材 | ~100s（CPU） |
| RVM 抠像 6061 帧 resnet50 ds0.4 | ~4 分钟（MPS） |
| 合成 + 编码 5063 帧 | ~1.5 分钟 |
| 只重做音轨（视频 copy） | ~10 秒 |

抠像缓存后，后面每轮调整只要 1.5 分钟，所以**值得多迭代几轮**。

## 事后看，最该早做的事

**先转写**。前面几轮都在调抠像和构图，其实那不是主要矛盾——三处念错和两段没剪的重录，才是评委真会扣分的地方，而它们只有逐字稿能暴露出来。
